# Security Policy

`agentsec` is an early defensive scanner for AI agent and MCP toolchains.

## Responsible Use

- Only scan systems you own or have permission to assess.
- Do not publish real secrets, private MCP configs, customer data, or company-identifying findings without permission.
- Prefer anonymized patterns when sharing research.
- Report concrete vulnerabilities to the affected project or vendor before public disclosure.

## Reporting Issues

For now, open a private issue or contact the maintainer directly before disclosing a vulnerability publicly.
