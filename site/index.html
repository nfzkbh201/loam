The missing layer

Code review checks what changed. Loam checks what the agent can now do.

01

Find authority paths

Loam traces how browser content, project instructions, MCP tools, credentials, and shell access can combine into risky execution chains.

02

Generate an ABOM

Every install creates a baseline Agent Bill of Materials: what agents can read, write, call, deploy, and approve.

03

Comment on PRs

Loam turns ABOM diffs into reviewable authority changes, so risky agent capabilities show up before merge.

PR review surface

The comment says what changed, why it matters, and what to review.
